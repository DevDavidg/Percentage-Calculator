# Percentage Calculator

React percentage calculator (ES/EN) built with [Vite](https://vitejs.dev/).

## Scripts

In the project directory, you can run:

### `npm start` / `npm run dev`

Runs the app in development mode.
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### `npm test`

Runs the Vitest test suite once.

### `npm run build`

Builds the app for production to the `dist` folder.

### `npm run preview`

Serves the production build locally for a quick smoke check.

## Hosting

Firebase Hosting serves the Vite `dist` output (`firebase.json` → `"public": "dist"`).
